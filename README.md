# DEADLINE: WASTELAND

A mobile-first 3D survival sandbox built for the web.

## Current playable build
- First-person / third-person camera
- Touch joystick + touch-look controls
- Keyboard/mouse fallback
- Hunger, thirst, health and stamina
- Harvest wood, stone and scrap
- Food and water consumption
- Crafting and inventory panels
- Zombies with noise-based aggro
- Melee combat
- Buildable barricades
- Drivable starter vehicle with fuel
- Day/night cycle
- Local save/load
- Responsive HUD
- GitHub Pages deployment workflow

## Controls
Mobile: left joystick moves, right side looks, buttons perform actions.

Desktop: WASD, Shift sprint, E harvest, F eat, G drink, R drive, Space attack, C camera, B build, L save.

## Roadmap
Vehicle repair/upgrades, collision/navigation, ranged weapons, loot containers, larger POIs, persistent world state, audio, quests, progression, and Pixel-class Android performance tuning are next.

## Deployment
The repository includes a GitHub Actions Pages workflow. GitHub Pages must be enabled with Source = GitHub Actions in repository Settings > Pages.
